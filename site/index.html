Ontologies About Use

Formal vocabularies for knowledge and record.

Epistemic Ontology is a small, curated namespace for OWL 2 DL and SKOS vocabularies that model how information is structured, trusted, and damaged. Every term has a stable, dereferenceable IRI under https://www.epistemic-ontology.net/.

Published ontologies

Record Harm Ontology

https://www.epistemic-ontology.net/record-harm#

A taxonomy of the ways an informational record can be damaged — prime harms (destruction, fabrication, alteration, omission, denial) and the composite harms built upon them — with SHACL validation and an event layer for specific occurrences.

OWL 2 DL SKOS SHACL v2.3

About

The goal is narrow and durable: a handful of carefully engineered, inter-operable vocabularies, each published at a permanent address so it can be cited, imported, and dereferenced for decades. Vocabularies here favour OWL 2 DL where reasoning matters, SKOS where a controlled vocabulary is enough, and SHACL for closed-world validation.

Maintained by Ron Hinchley. Source and issue trackers are linked from each ontology's page.

Using a vocabulary

Each term IRI resolves to both human documentation and machine RDF, by content negotiation:

# Human-readable documentation
curl -H "Accept: text/html" https://www.epistemic-ontology.net/record-harm

# Turtle (also: application/rdf+xml, application/ld+json)
curl -H "Accept: text/turtle" https://www.epistemic-ontology.net/record-harm

IRIs use hash namespaces (e.g. …/record-harm#Destruction), so dereferencing any term fetches the whole vocabulary document.
